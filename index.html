Deterministic document engine

Production architecture
ProblemRAG breaks on messy financial tables and wastes money on bad model calls.
SystemMulti-retrieval with caching. If local parsing fails on a scan, OCR switches to Mistral, LlamaParse, or Google. Python does the table math instead of the LLM. Runs on cloud APIs or a local GPU.
EvaluationThree guards check the question, the retrieved text, and the final numbers against the source file before replying.
Saved517 of 517 table rows exact, up from 93. 100-page scans dropped from 7.5 minutes to seconds.
ShippedUser app, admin trace view, API, and background worker.
Stack: Python · FastAPI · PostgreSQL · Redis · ChromaDB · PyMuPDF4LLM · Docling · Mistral OCR · LlamaParse · Google Document AI · OpenRouter · Local LLMs · Docker

Legacy CMS, booking, and payment migration

Production architecture

Hospital patient record OCR and human-in-the-loop review

Production architecture
ProblemA hospital had a backlog of handwritten and printed clinical sheets (including cholesterol and lab records) across multiple languages. Staff uploaded files through Microsoft Forms and a slow PHP sorter, leaving patient records lagging and feeding dirty data into the hospital CRM.
SystemBuilt a patient-isolated ingestion pipeline with two-level OCR (local OCR plus Llama vision OCR) and zero-account scoped access logs. The pipeline reads the scan, links the patient name to the existing CRM profile, and cites the exact region on the page for every value.
EvaluationEvery extracted field gets a confidence score. High-confidence values pass straight through. When handwriting is unclear, the review screen shows the document, what was cited, and the exact fields where an error is likely so staff fix just that spot without reading the whole file. Human corrections feed back into the correction model.
SavedEliminated the Microsoft Forms and PHP sorting bottleneck, cut manual review fatigue, and delivered clean, verified patient data to the CRM and data analytics team.
ShippedTwo-level OCR pipeline, grounded citation and error-highlight review UI, CRM patient matcher, zero-account access audit log, and correction training loop.
Stack: Python · FastAPI · Two-Level OCR (Local + Llama Vision) · Grounded Citations · Human-in-the-Loop Review · CRM Sync · Scoped Audit Logs

Real-time fintech reconciliation engine

Production architecture
ProblemThe partner bank API took 48 hours to settle. Checking bank balances directly risked negative accounts during concurrent spend.
SystemA plain-code shadow ledger locks funds at T+0 and reconciles them against T+2 bank webhooks and batch files.
EvaluationChecked every state change against out-of-order webhooks, partial clears, and reversals before releasing holds.
SavedCut pipeline cost per user from 72% to 17%, reduced operational risk by 15%, and processed $122K in volume with zero float.
ShippedShadow ledger, 3-way reconciliation worker, exception queue, and spend Chrome extension.
Stack: Python · SQL · Double-entry ledger · Webhook consumers · REST banking APIs
